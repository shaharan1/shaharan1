# Theme preview for profile-summary cards

Below are example links to generate profile summary cards using different themes. These reference the live github-readme-stats service so you can preview and copy the markdown.

```
[![Stats](https://github-readme-stats.vercel.app/api?username=shaharan1&show_icons=true&theme=tokyonight&hide_border=true&include_all_commits=true&count_private=true)](https://github.com/anuraghazra/github-readme-stats)
```

```

Top languages (compact) — example themes:

```
![Top Langs - Tokyonight](https://github-readme-stats.vercel.app/api/top-langs/?username=shaharan1&layout=compact&theme=tokyonight&hide_border=true)
