## 👋 A little about me

Hi, I'm **Shaharan**, a Java developer from Dhaka, Bangladesh.

I enjoy the kind of software that helps a real business run better: the forms, the workflows, the reports and the databases behind them. Right now I work as an **Executive-IT (Application)** at **Primitek Group**, where I spend my days around ERP systems, especially **iDempiere**.

Outside of work, I build complete systems that run across platforms: a **Hospital Management System** with a Spring Boot backend and both Android and Flutter apps, and a **Hotel Management** web app in Angular. I'm also learning how to make my code cleaner, safer and easier to test.

My goal is simple: keep improving as a backend-focused Java developer, and one day work with an international team in **Europe** 🇪🇺.

**Right now I'm:**

- 🔭 Building management systems across web and mobile (Spring Boot, Angular, Flutter, Android)
- 🌱 Learning Spring Security, JUnit/Mockito and Docker
- 🤝 Open to collaborating and talking with other developers
